前言

以前我一直觉得有关像素的知识少而少之，上手门槛非常之低，直到我正式开始接触像素风格游戏开发一个月后…

法线贴图

  • 参考教程：

【游戏开发基础知识】深入了解法线贴图_哔哩哔哩_bilibili

  • 什么是法线？

答：假如有一个平面，法线就是垂直于平面的向量，可以用来对比光源方向的相似性，来计算简单光影，虽然视频中没有明说，但是根据给出的样图可以联想到，由于法线永远垂直于平面，一个球的法线与光照方向一定会有非常多的角度，从与光源方向向量完全相反（代表受光照效果最强），到与光源方向向量完全相同（代表完全不受光照效果影响）。虽然从物理上来说并不能这么简单的推断光与影的明暗关系，所以说是计算简单光影

Godot - 项目日志 - 主界面

发表于 2026-05-02 更新于 2026-05-08 分类于 Godot ， Godot毕设项目

前言

我希望达成的效果是：

侧边抽屉 + 中心聚焦轮播菜单

也就是一个 随状态切换的多节点同步Tween动画

屏幕最左侧有一个按钮，按下后会从左边出现一个竖着的循环轮播按钮菜单，同时整个主场景也会像右边移动，在这个菜单里，有通向各个页面的自制按钮，当自制按钮没有处在中间时，颜色变暗，且保持闲置状态不动，当处在中间时，按钮获得一个白色虚框表示获得焦点，且开始播放按钮的动画

结构

  • 参考结构：

Main (Node) ← Main.gd
├── MainBackground (Node2D) ← World.gd
│ ├──背景的精灵图，灯光，特效等
│ ├── PlayerSpawnPoint (Marker2D)
│ ├── Player（运行时生成）
│
├── UI (CanvasLayer)
│ └── MainUI (Control) ← MainUI.gd
│ ├── MainScene (Control)
│ ├── SideMenu (Control) ← SideMenu.gd
│ │ ├── MenuContainer (Control)
│ │ │ ├── MenuButton × N ← MenuButton.gd
│ ├── Overlay (ColorRect)
│ ├── ToggleButton (Button)

视觉容器和ui解耦

节点 负责
Main 启动世界
MainBackground 玩家 / 位置 / 逻辑
CanvasLayer UI隔离
MainUI 抽屉动画
SideMenu 轮播逻辑
Button 聚焦时动画表现

关于左菜单抽屉

使用 tween 动画可以让左侧菜单平滑的划出，可以让主场景平滑的右移

  • 结构

首先我们有两种动画：整个抽屉从左边拉出来的动画，轮播按钮上下滑动的动画

第 1 行负责的是整体抽屉的左右移动，第 2 行负责的是内部按钮的移动，第 3 行即是按钮元素

毕业论文格式要求

发表于 2026-04-05 分类于 杂项 ， 重庆工程学院毕设论文格式要求

小技巧

  • 打开新的修改工作和修改工作几乎做完时，ctrl + a 选中全部文字，设置字体 => 西文字体 => TimeNewRoma
  • 格式刷快捷键：Ctrl + Shift + C，Ctrl + Shift + V
  • 左上角文件 => 选项 => 视图 => 格式标记 => 勾选全部

基础格式

摘要

  • 摘要标题 ：为一级标题，中间两空格！
  • 摘要正文 ：格式为正文
  • 关键词 ：黑体，小四，无需首行缩进，关键词之间用 ；隔开

ABSTRACT（英文摘要）

  • 英文摘要标题 ：TimeNewRoma，三号，固定值20磅，居中，前后空一行，空行格式为正文
  • 英文摘要正文： 格式为正文
  • 关键字 ：加粗

目录

  • 目录标题： 为一级标题，中间两空格！
  • 目录内容：格式为正文，注意符号与英文格式为 TimeNewRoma

参考文献

  • 参考文献标题：一级标题
  • 参考文献内容：五号，悬挂缩进2字符！注意符号与英文格式为 TimeNewRoma

致谢

  • 致谢标题： 为一级标题，中间两空格！
  • 致谢内容：格式为正文，注意符号与英文格式为 TimeNewRoma

一级标题

1 绪 论

  • 黑体，三号，固定值20磅，居中，前后空一行，空行格式为正文

二级标题

1.1 研究目的及意义

  • 中文：黑体，小三，固定值20磅，大纲级别：2级
  • 其他字符：TimeNewRoma，设置方式见 小技巧

三级标题

​ 1.1.1 国内研究现状

  • 中文：黑体，四号，固定值20磅，大纲级别：3级
  • 其他字符：TimeNewRoma，同上

正文

  • 中文：宋体，小四！，固定值20磅，首行缩进
  • 其他字符：TimeNewRoma，同上

图片

  • 格式：嵌入式，单倍行距！（行距设置为固定值会压缩图片！），居中显示，无首行缩进！
  • 图注：位于图片下方，居中显示，五号，无首行缩进！
  • 图注内容：图x.x 图名，x.x代表当前x章的第x张图，如第二大章的第三张图：图2.3 xxxxxxxx

表格

  • 格式：三线表，上下边框为1.5磅实线，表头下边框为0.5磅实线
  • 内容格式：
    • 中文：五号，宋体，是否居中，根据具体情况判断，一般格式没有太乱的就不管
    • 其他字符：TimeNewRoma，其他同上
  • 表注：位于表格上方，居中显示，五号，无首行缩进！
  • 表注内容：表x.x 表名，x.x代表当前x章的第x张表，如第二大章的第三张表：表2.3 xxxxxxxx
  • 续表：当所有格式调整至差不多时，表格无法放在一页且没有办法较好调整至一页时，需要续表，在表格需要断掉的单元格下按 Ctrl + Shift + 回车，断开表格，在新的表格上方添加新的表注，格式为原表注最后 + （续）

代码

  • 格式：0.5磅实线边框全包裹，如出现边框不正常显示，则修改代码内容格式，不要有缩进
  • 内容格式：小四

其他格式

页眉

  • 下划线使用表格下边框
  • 格式：五号，固定值20磅，只有一行，无多余空行
  • 左侧为 重庆工程学院本科生毕业设计（论文），中间使用空格隔开，右侧为 域代码
  • 域代码插入方式：插入 => 文档部件 => 域 => 样式引用 => 样式名 => 一级标题（你设置的大纲级别为1的样式名），设置你要引用的文本格式为一级标题

注意点

  • 在调整页眉格式时，选中上方菜单栏，页眉同前节取消勾选，奇偶页不同取消勾选，同前节取消勾选

页脚

  • 摘要起，以罗马数字到目录
  • 绪论起，以阿拉伯数字到论文结束
  • 格式：居中，五号
  • 设置方式：点击页脚 => 页码设置，重新编号
