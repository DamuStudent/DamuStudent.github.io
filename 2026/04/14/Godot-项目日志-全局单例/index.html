前言

  • 关于全局单例的项目日志

WeaponManager 武器管理器

  • 设计初衷是管理 玩家手持武器 ， 玩家更换武器 ， 武器词缀更新 ， 武器等级更新
  • 特殊属性和词缀属性都存储在一个字典里
  • 方法1 到 方法4 为玩家切换武器时会调用的
  • 方法5 到 方法9 都是掉落武器时会调用的

信号

  • 暂无

变量

武器id：作为玩家武器背包中每一把武器的唯一id

武器等级：在玩家刷武器时根据玩家等级生成

武器名字：通过随机算法在关卡可掉落武器中随机生成

武器品质：影响掉落几率

武器类型：影响玩家手持方式，影响玩家攻击动画

武器流派：在玩家刷武器时影响武器词缀和武器面板伤害生成

武器攻速：获取的数据库数据，单位为 次/每秒

武器伤害：动态生成

武器图片：在玩家刷武器时通过随机算法确定的武器名字后，从数据库访问武器表获取，在玩家查看武器时给出图片，在玩家装备武器时将图片挂载到武器节点下

武器特殊效果：该武器佩戴时的固定特殊属性加成

武器特殊效果描述：当玩家查看武器时给出的文字提示

武器伤害表达式：策略模式的相对路径

武器伤害表达式描述：当玩家查看武器时给出的文字提示

武器词缀相关变量：在玩家刷武器时动态生成，掉落管理器会调用武器管理器中的词缀生成功能

武器特殊属性：在玩家节点添加武器时在玩家属性中减去旧的特殊属性，并加入玩家属性，当该武器被卸下后被玩家属性减去

词缀品质枚举

词缀类型枚举

词缀数据字典

方法

方法1：spawn_weapon_instance(new_weapon_id: int, parent: Node2D, position: Vector2) -> Node2D

功能：实例化一个武器节点并调用 方法2

参数：
new_weapon_id：武器的模板ID（整数）
parent：父节点（Node2D 类型）
position：武器实例的初始位置（Vector2 类型）
返回：
返回实例化的武器节点（Node2D 类型）

方法2：load_from_template_id(template_id: int) -> bool

功能：通过 武器id 从数据库中加载 武器数据 并初始化当前武器实例节点的各个属性（图片、伤害策略，词缀）

参数：
template_id：武器的模板ID（整数）
返回：
返回 true 如果成功加载模板，否则返回 false（布尔值）

方法3：reset_special_properties()

功能：重置所有特殊属性和词缀属性为 0

参数：无
返回：无（void）

方法4：apply_affix_to_properties(affix_data: Dictionary)

功能：将单个词缀加入至特殊属性字典上

参数：
affix_data：词缀数据字典，格式为 { “type”: “词缀类型”, “value”: 词缀值 }
返回：无（void）

方法5：get_quality_probabilities(weapon_level: int) -> Dictionary

功能：根据武器等级返回词缀品质的概率分布

参数：
weapon_level：武器等级（整数）
返回：
返回一个字典，键为词缀品质枚举（AffixQuality），值为概率（浮点数）

方法6：get_random_quality(probabilities: Dictionary) -> int

功能：根据概率分布随机选择一个词缀品质

参数：
probabilities：词缀品质概率字典，格式为 { AffixQuality.XXX: 概率 }
返回：
返回选中的词缀品质枚举（AffixQuality 类型，整数）

方法7：get_random_affix_type() -> int

功能：随机选择词缀类型（百分比或数值）

参数：无
返回：
返回词缀类型枚举（AffixType.PERCENTAGE 或 AffixType.VALUE，整数）

方法8：generate_single_affix(quality: int, affix_type: int) -> Array

功能：根据品质和类型生成单个词缀

参数：
quality：词缀品质枚举（AffixQuality 类型，整数）
affix_type：词缀类型枚举（AffixType 类型，整数）
返回：
返回一个数组，格式为 [词缀类型字符串, 随机值]（例如 [“attack_percentage”, 0.05]）

方法9：generate_affixes(weapon_level: int) -> Dictionary

功能：根据武器等级生成一组词缀

参数：
weapon_level：武器等级（整数）
返回：
返回一个字典，键为 weapon_affix_1 到 weapon_affix_N，值为格式化的词缀字符串（例如 “attack_percentage,0.05”）
总结

PlayerManager 玩家管理器

  • 主要管理玩家的相关属性
  • 影响玩家属性

影响玩家属性层的主要因素有:

玩家升级固定增加的属性

玩家升级后升级点在天赋树添加或修改的属性

武器被玩家手持时持有的属性

换武器时要先把玩家属性减去武器持有属性然后再加上新的武器的属性

装备被玩家装备时增加的属性

装备被玩家卸掉时玩家属性要减去装备属性

换装备时要先减去原装备属性，再加上新装备属性

  • 将分为局内属性和局外属性，其实就是基本属性和叠加属性
