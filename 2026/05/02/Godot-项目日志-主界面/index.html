Godot - 项目日志 - 主界面

发表于 2026-05-02 更新于 2026-05-08 分类于 Godot ， Godot毕设项目

前言

我希望达成的效果是：

侧边抽屉 + 中心聚焦轮播菜单

也就是一个 随状态切换的多节点同步Tween动画

屏幕最左侧有一个按钮，按下后会从左边出现一个竖着的循环轮播按钮菜单，同时整个主场景也会像右边移动，在这个菜单里，有通向各个页面的自制按钮，当自制按钮没有处在中间时，颜色变暗，且保持闲置状态不动，当处在中间时，按钮获得一个白色虚框表示获得焦点，且开始播放按钮的动画

结构

  • 参考结构：

Main (Node) ← Main.gd
├── MainBackground (Node2D) ← World.gd
│ ├──背景的精灵图，灯光，特效等
│ ├── PlayerSpawnPoint (Marker2D)
│ ├── Player（运行时生成）
│
├── UI (CanvasLayer)
│ └── MainUI (Control) ← MainUI.gd
│ ├── MainScene (Control)
│ ├── SideMenu (Control) ← SideMenu.gd
│ │ ├── MenuContainer (Control)
│ │ │ ├── MenuButton × N ← MenuButton.gd
│ ├── Overlay (ColorRect)
│ ├── ToggleButton (Button)

视觉容器和ui解耦

节点 负责
Main 启动世界
MainBackground 玩家 / 位置 / 逻辑
CanvasLayer UI隔离
MainUI 抽屉动画
SideMenu 轮播逻辑
Button 聚焦时动画表现

关于左菜单抽屉

使用 tween 动画可以让左侧菜单平滑的划出，可以让主场景平滑的右移

  • 结构

首先我们有两种动画：整个抽屉从左边拉出来的动画，轮播按钮上下滑动的动画

第 1 行负责的是整体抽屉的左右移动，第 2 行负责的是内部按钮的移动，第 3 行即是按钮元素
